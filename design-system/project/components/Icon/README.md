# Icon

The kit's 16×16 glyph set, drawn in `currentColor`.

**You provide:** `name` (see `SongQuiz.iconNames`), `size` (px, default 16), `title` (only when the glyph stands alone and needs a name; otherwise it is hidden from screen readers).

- 12px in controls, 16px in the source list, 8–10px in badges.
- Colour comes from the parent: `ink` on chrome, `source-icon` in the sidebar, `lcd-muted` in the LCD.
