# NowPlaying

Sidebar panel under the source list showing the current track's art, with a caption. During a round it shows a hidden sleeve.

**You provide:** `label` (default "Now Playing"; "Last song" after a reveal), `art`, `title`, `subtitle`, `hidden`.

- While guessing: `hidden`, title "Mystery track", subtitle "Revealed when time runs out".
- After the reveal: the real art, title and "Artist · Year".
