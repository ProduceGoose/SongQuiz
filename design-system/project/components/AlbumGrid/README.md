# AlbumGrid

The dark album-art wall that lays `AlbumTile`s out in even, responsive columns.

**You provide:** `AlbumTile` children, `label` for the list (e.g. "Answer choices"), optional `size` (art px; default `art-md` 96px).

- Use 4–8 answer choices per round. More turns guessing into scanning.
- Put the round prompt (`question` style, `grid-ink`) above the grid, on the same `grid-bg`.
