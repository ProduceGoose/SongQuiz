# Button

Aqua-era pill push button: silver by default, glossy `aqua` for the one primary action on screen.

**You provide:** `children` (label), `variant` (`default` | `primary`), `size` (`md` | `lg`), optional `icon`, `onClick`, `disabled`, `type`.

- Use one primary per screen: "Start game", "Lock in", "Next round".
- Labels are verbs in sentence case. "Waiting…" on a disabled button is fine.
- `lg` buttons pair with the large answer field.
