# GameScreen

A round in progress, built only from the kit: Window, Toolbar (Transport, VolumeSlider, LcdDisplay, SegmentedControl, SearchField), SourceList with a hidden NowPlaying, the round prompt, the answer field with "Lock in", an AlbumGrid of six choices and the StatusBar.

Use it as the reference layout for the round screen. The lobby swaps the grid for the player list, and the scores view swaps it for a `Leaderboard`.
