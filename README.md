# SongQuiz

A multiplayer song quiz to play with friends, styled like a late-2000s desktop jukebox.

The design system (tokens, React components, previews, usage rules) lives in `design-system/project/`:
start with `design-system/project/README.md`. Each component folder in
`design-system/project/components/` holds a `README.md` (usage), and a live preview split into
`preview.html`, `style.css` and `script.js`; example data shared by the previews is in
`components/demo/demo-data.js`.

The clickable menu prototype lives in `web/`: open `web/index.html` in a browser. See `web/README.md`.
